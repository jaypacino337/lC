# assets

- `mark.svg`: nav mark + favicon (graphite/orange).
- `banner.png`: 1280×640 Open Graph / X card, rendered from the site's own CSS.
- `fonts/`: self-hosted Inter Tight + JetBrains Mono (OFL, see `fonts/LICENSE.md`).

To use real brand art, replace `mark.svg` / `banner.png` with files of the same name
and size. The banner must be at least 1200×630 or social platforms crop or refuse it.
